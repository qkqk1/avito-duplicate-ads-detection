# Поиск дублей объявлений

Классификатор пар объявлений: по двум объявлениям определяет, описывают ли они один и тот же товар. Данные взяты из соревнования Kaggle [Avito Duplicate Ads Detection](https://www.kaggle.com/c/avito-duplicate-ads-detection).

## Задача

Для пары объявлений нужно предсказать `isDuplicate`: 1, если это один и тот же товар, и 0, если разные. У каждого объявления есть заголовок и описание на русском языке, цена, категория, атрибуты, местоположение и идентификаторы фотографий.

## Данные

Используются четыре обучающих файла соревнования. Распакованные CSV должны лежать в `data/raw/kaggle/`. Папка `data/` в репозиторий не попадает.

| Файл | Содержимое | md5 |
|------|------------|-----|
| `ItemPairs_train.csv` | пары объявлений и метка `isDuplicate` | `a94f960f1d1b30e037490bbc37f21b48` |
| `ItemInfo_train.csv` | тексты, цена, категория, место и прочие поля объявлений | `27830ac45148f2ed436ae7e8c47a2827` |
| `Category.csv` | категории и родительские категории | `92df89ecd61248eca1fd4a3ab6763aa7` |
| `Location.csv` | локации и регионы | `15c2cf875e980dab1f7684973b335f2c` |

Суммы посчитаны для распакованных файлов. Проверка своей копии:

```
poetry run avito-dups md5 data/raw/kaggle/ItemPairs_train.csv
```

Даты публикации в таблицах нет, так что проверки по времени не будет.

Для работы CSV переводятся в Parquet командой `poetry run avito-dups build-dataset`. Результат попадает в `data/processed/`: `items.parquet` с объявлениями и `pairs.parquet` с парами.

## Колонка generationMethod

В `ItemPairs_train.csv` у каждой пары есть поле `generationMethod`, которое показывает происхождение метки:

- 1 — метку поставили люди, видевшие только эту пару;
- 2 — метку поставили автоматические алгоритмы;
- 3 — метку поставили люди, просматривавшие все объявления одного продавца.

Уровень шума в метках у этих способов разный. Как признак колонка не используется: для новой пары в сервисе её значения взять неоткуда. Метрики считаются и в целом, и отдельно по каждому способу, чтобы видеть, на каких парах модель ошибается.

## Метрики

Метрика соревнования: ROC-AUC. Модели между собой сравниваются по PR-AUC, потому что она лучше отражает качество на классе дублей. Ложная склейка вредит добросовестному продавцу сильнее, чем пропущенный дубль, поэтому порог подбирается по precision, а recall смотрится при выбранном пороге.

## Валидация

Одно объявление может входить в несколько пар. При случайном разбиении пар оно попадало бы и в обучение, и в проверку, а оценка качества получилась бы завышенной. Поэтому разбиение делается по группам объявлений.

## Запуск

Нужны Python 3.11 или 3.12 и Poetry 2.

```
poetry install
poetry run avito-dups build-dataset
poetry run pytest
```
