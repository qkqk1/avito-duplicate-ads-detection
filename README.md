# Поиск дублей объявлений

Классификатор пар объявлений: определяет, описывают ли два объявления один и тот же товар.
Данные: соревнование Kaggle [Avito Duplicate Ads Detection](https://www.kaggle.com/c/avito-duplicate-ads-detection).

## Задача

Бинарная классификация пары объявлений: `isDuplicate` равен 0 или 1.
Исходные данные пары: тексты на русском, цена, категория, атрибуты, идентификаторы изображений.

## Данные

Используется выборка из 20 000 пар объявлений (24 колонки) из обучающих данных соревнования. Дубли составляют 42,5 % пар.
Выборка скачивается с [зеркала на GitHub](https://github.com/joostgp/kaggle_ad_detection) командой из раздела «Установка и запуск», после загрузки проверяется md5.

## Метрики

| Метрика | Применение |
|---|---|
| ROC-AUC | метрика соревнования |
| PR-AUC | сравнение моделей |
| Precision, recall | оценка при выбранном пороге |

Приоритет у precision: ложная склейка вредит продавцу сильнее пропущенного дубля.

## Валидация

Групповая по объявлению: одно объявление входит в несколько пар.

## Установка и запуск

Требуется Python 3.11 или 3.12 и Poetry 2.x.

```bash
poetry install
poetry run avito-dups download-sample
poetry run pytest
```
